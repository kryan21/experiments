# Experiments — KRYAN

A lab repo. Every experiment lives in its own folder as a ready-to-open build
(GitHub Pages serves them), with its source kept under [`source/`](source/).

| Experiment | Live | What it is |
|---|---|---|
| Sphere Gallery | [Open](sphere-gallery/) | MotionSites-inspired portfolio: chrome sphere hero, the sphere exploded into a draggable 3D sphere of project tiles. React + Three.js (R3F) + Framer Motion. |
| Vante Ribbon Hero | [Open](vante-ribbon-hero/) | MotionSites "Video Ribbon" hero v2: a cylinder carousel of thumbnails revolving around a giant condensed headline — tiles swell on the close pass, settle into an accessible 3x2 grid, ~14s loop. React + Three.js (R3F). |

Rules of the lab: study the reference live first, rebuild it in our own stack
with original wording, verify from real renders — never copy paid source.
